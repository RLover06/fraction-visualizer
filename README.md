# 🍕 Fraction Visualizer

Interactive web page that shows any fraction as a **pie**, a **grid** and a **bar** at the same time, to help students understand how the numerator and denominator relate to parts and units — including improper fractions shown as several whole units.

🔗 **Live demo:** https://rlover06.github.io/fraction-visualizer/

## Features
- Type any fraction (e.g. `3/4`, `8/3`) and see three representations side by side.
- Improper fractions are drawn as multiple whole units.
- Spanish / English language toggle.
- Single HTML file — no installation, works in any browser.
